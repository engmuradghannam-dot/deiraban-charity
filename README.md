# نظام عضوية جمعية ديرابان الخيرية

نظام Django + React لإدارة سجل أعضاء الجمعية، مبني من كشف الأعضاء الأصلي (887 عضواً، مقسّمين على العائلات، مع سجل اشتراكات 2019–2025).

## المرحلة الحالية (MVP)

تم بناء هذا الإصدار كنواة أساسية جاهزة للتشغيل:

- **Backend (Django + DRF)**: نماذج `Family` و`Member`، واجهة API كاملة (بحث، فلترة حسب العائلة/الحالة، إحصائيات)، لوحة تحكم Django Admin جاهزة للتعديل اليدوي.
- **استيراد البيانات**: أمر إدارة (`import_members`) يستورد البيانات من `data/members.csv` — وهو ملف تم استخراجه آلياً من ملف PDF الأصلي (887 سجلاً، بدون فاقد).
- **Frontend (React + Vite)**: لوحة عرض وبحث بالعربية (RTL) — بحث فوري، فلترة حسب الحالة والعائلة، وجدول اشتراكات سنوي.

### ⚠️ ملاحظة مهمة حول دقة البيانات
قيم سنوات الاشتراك (2019–2025) استُخرجت آلياً من جدول PDF كان النص فيه معكوساً (مشكلة شائعة في تصدير PDF بالعربية). تم التحقق من ترتيب الأعمدة على عدة صفوف ويبدو صحيحاً، لكن يُنصح **بمراجعة عينة من الأرقام يدوياً مقارنة بالكشف الأصلي** قبل اعتماد البيانات في أي قرار مالي أو إداري. حالات العضوية (فاعل/غير فاعل/جديد) تم التحقق منها بدقة: 521 فاعل، 342 غير فاعل، 24 جديد.

## ما لم يُبنَ بعد (يحتاج جلسة Claude Code لإكماله)

المشروع الوصفي اللي أرسلته (تسجيل دخول Google، الانتخابات، التبرعات) نظام كبير متعدد الوحدات — بناؤه الكامل بجودة إنتاجية يحتاج جلسة عمل تكرارية (تطوير + اختبار + تصحيح) وهذا متوفر بشكل أفضل في **Claude Code** وليس في محادثة واحدة. هذا المشروع هنا هو الأساس الصلب (قاعدة بيانات + API + واجهة) اللي تُبنى عليه بقية الوحدات مباشرة بنفس الـ stack.

## التشغيل محلياً

### Backend
```bash
cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py import_members          # استيراد بيانات الأعضاء من data/members.csv
python manage.py createsuperuser         # لإنشاء حساب مدير للدخول على /admin
python manage.py runserver
```
الـ API يعمل على: `http://127.0.0.1:8000/api/`
لوحة الإدارة: `http://127.0.0.1:8000/admin/`

### Frontend
```bash
cd frontend
npm install
npm run dev
```
الواجهة تعمل على: `http://localhost:5173` (معدّة للاتصال بالـ backend تلقائياً عبر proxy)
